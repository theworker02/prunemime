# prunemime

Prune filesystem mime paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/prunemime/

## Install / run

```bash
git clone https://github.com/theworker02/prunemime.git
cd prunemime
node src/cli.js
node --test
```
